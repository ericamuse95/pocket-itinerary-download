# Pocket Itinerary

Plan vacations, manage excursions, generate upcoming trip reports,
and view destination travel advisories.

[Download Pocket Itinerary for Android](https://github.com/ericamuse95/pocket-itinerary-download/releases/latest/download/app-release.apk)

## Requirements

- Android 8.0 or later
- Internet connection for account access and cloud features

## Installation

1. Download the APK using the link above.
2. Open the downloaded file.
3. If prompted, allow installation from your browser or file manager.
4. Tap Install.
5. Open Pocket Itinerary and tap Enter.
6. Create an account or sign in.
